# ElytraMace

ElytraMace is a Minecraft mod that allows players to switch between elytra and chestplate while flying, specifically when using a mace. This mod is designed to enhance the gameplay experience by providing a seamless transition between armor pieces during flight, making it easier to attack enemies while maintaining the benefits of elytra flight.

## Install

1. Download the mod file from the [GitHub repository](https://github.com/enderdevelopment/elytrachestplateswitch).
2. Place the downloaded file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft and ensure the mod is loaded.

## Use

1. Equip both an elytra and a chestplate.
2. Start flying with the elytra.
3. Hold a mace in your main hand.
4. Press the attack key to switch between elytra and chestplate while flying.
